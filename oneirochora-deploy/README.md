# 🌟 Ονειροχώρα — Σύστημα Διαχείρισης

Πλήρες, έτοιμο-για-ανέβασμα React project.

## 📁 Τι περιέχει αυτός ο φάκελος

```
oneirochora-deploy/
├── src/
│   ├── App.jsx        ← Η εφαρμογή σου (όλη η λογική εδώ)
│   └── main.jsx        ← Entry point (μην το αγγίξεις)
├── index.html
├── package.json
├── vite.config.js
├── vercel.json         ← Ρυθμίσεις για σωστό routing στο Vercel
└── .gitignore
```

## 🚀 Ανέβασμα σε 3 βήματα (Vercel — δωρεάν)

### 1. Ανέβασέ το στο GitHub
Ανέβασε ολόκληρο αυτόν τον φάκελο σε νέο repository στο https://github.com
(μπορείς να το κάνεις drag & drop από το GitHub website — δεν χρειάζεται terminal)

### 2. Σύνδεσε το Vercel
- Μπες στο https://vercel.com → **Sign Up** → **Continue with GitHub**
- **Add New → Project** → επίλεξε το repository σου → **Import**

### 3. Deploy
- Άφησε όλες τις ρυθμίσεις όπως είναι (το Vercel αναγνωρίζει αυτόματα Vite)
- Πάτα **Deploy**
- Σε ~1 λεπτό η εφαρμογή σου είναι ζωντανή σε διεύθυνση τύπου:
  `https://oneirochora.vercel.app`

## 💻 Δοκιμή στον υπολογιστή σου πριν το ανέβασμα (προαιρετικό)

Αν έχεις εγκατεστημένο Node.js (https://nodejs.org, έκδοση LTS):

```bash
npm install
npm run dev
```

Θα ανοίξει σε `http://localhost:5173`

## 🔐 Λογαριασμοί & κωδικοί πρόσβασης

Οι κωδικοί ΔΕΝ είναι πλέον σε κοινή χρήση — κάθε άτομο έχει το δικό του λογαριασμό.
Βρίσκονται στην αρχή του `src/App.jsx`, στον πίνακα `USERS`.

**Μέσα στην εφαρμογή:** σύνδεση ως Διοίκηση → μενού **«Χρήστες»** → κουμπί
**«🖨️ Κάρτα στοιχείων προσωπικού»** δείχνει όλους τους κωδικούς σε καθαρή μορφή,
έτοιμη για εκτύπωση ή αντιγραφή, ώστε να τους δώσεις στον καθένα.

**Λογαριασμοί γονέων:** ΔΕΝ δημιουργούνται εδώ. Κάθε γονέας παίρνει username/κωδικό
όταν καταχωρείτε το παιδί του στο **Μητρώο** (Βήμα 3 της φόρμας «+ Νέο παιδί»).

## 🔧 Πώς κάνεις αλλαγές στο μέλλον

1. Άνοιξε το `src/App.jsx` με οποιοδήποτε text editor (ή ζήτα μου να το επεξεργαστώ)
2. Κάνε τις αλλαγές
3. Ανέβασέ τις στο GitHub (commit + push, ή drag & drop αντικατάσταση αρχείου)
4. Το Vercel ανανεώνει αυτόματα σε ~1 λεπτό

## ⚠️ Σημαντική σημείωση

Αυτή τη στιγμή η εφαρμογή είναι **frontend only** — τα δεδομένα (παιδιά, μηνύματα, έξοδα,
χρήστες που προσθέτεις) **δεν αποθηκεύονται μόνιμα**, χάνονται σε κάθε refresh. Ιδανικό
για επίδειξη/δοκιμή.

Για μόνιμη αποθήκευση δεδομένων και πραγματικά push notifications χρειάζεται σύνδεση
με βάση δεδομένων (προτείνεται Supabase — δωρεάν tier). Αυτό είναι το επόμενο βήμα.
